# dev-tools v0.4.1

补齐 Windows / WSL 软件更新检查，增加 Microsoft Store、Snap 和 Rustup 覆盖。

## 更新检查

- mise 用 `outdated --json` 查询当前声明允许的更新，遵守固定版本和发布冷却策略；历史缓存版本仍只作为安装清单记录。
- Store 用微软官方 CLI 查询已安装商店应用，补上 winget 未匹配的范围；目标版本未提供时记为未知，不使用 `--apply`。
- Snap 用 `refresh --list` 查询版本和 revision 更新，不安装应用。
- Rustup 查询 Windows / WSL 原生工具链更新，正确处理表示可更新的退出码 100。
- 新增查询输出结构化 `updates`。工具缺失、未知输出和部分成功分别记录；Store 的非交互确认错误保留已取得结果并标记 `partial`。

## 配置与附件

默认采集器新增 `store`、`snap`、`rustup`。已有显式 `collectors` 列表保持原值，需要在本机 `config.toml` 中启用新项；npm 是否采集仍由现有配置决定。

附件为 `dev-tools-0.4.1.zip`、`SHA256SUMS` 和 `dev-tools.json`。Windows / WSL 部署分别更新，更新前停止对应平台的活动项目；安装器保留本机偏好、注册、状态、缓存和项目运行时。

详见[运行与配置说明](../usage.md)和[完整更新记录](../../CHANGELOG.md)。

## English brief

- Query mise updates allowed by current declarations, preserving version pins and release-age policy.
- Add native Microsoft Store, WSL Snap and Windows/WSL Rustup update queries with structured version facts.
- Keep unavailable Store target versions unknown; retain valid results as partial when its confirmation rejects redirected input.
- Preserve explicit collector lists. Enable `store`, `snap` and `rustup` in native user configuration when needed.

See the [usage guide](../usage.en.md) and [installation guide](../installation.en.md).
