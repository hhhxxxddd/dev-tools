# v0.5.3

## 中文

- 新增 Windows / WSL 工具箱：`ports list/show` 查看真实端口与进程，`which` 溯源 PATH，`net info/check` 查看网络设置并分阶段诊断直连；支持双向调用及 JSON。
- 端口查询按需采集，Windows 使用标准库调用原生 API，WSL 跳过无匹配端口的进程扫描。Git 监控每轮由 3 次调用减为 1 次，自动发现合并目录遍历。
- 扫描与监控跳过目录联接、符号链接和非普通元数据文件；无效声明给出校验错误，损坏的单个注册不再遮蔽其他项目。
- 修复关闭报告刷新后仍查询 npm 更新，限制 SSH Include 展开，Compose 健康查询超时为 5 秒。
- 所有工具箱裸命令显示帮助。SSH 增加来源查看、编辑和原生连接；Windows hosts 增加方案切换、编辑、冲突检查、自动备份和恢复。
- `list` 默认当前环境，`--all` 汇总两端；`-e win|wsl` 统一用于项目、配置、报告、SSH 和自身维护。`self status` 返回所选目标的部署状态（schema_version=1）。
- 修复 WSL root/sudo 的 Windows PowerShell 发现、Windows 配置文件占用、特殊字符与报告路径传输；完善更新恢复、规范检查和双语文档。

```text
dev-tools ports show 3000 -e win
dev-tools which python -e wsl
dev-tools net check http://localhost:3000/health -e wsl
dev-tools list --all
```

查询保持只读；hosts 系统写入按需提权并备份。控制器 Python 要求仍为 `>=3.14.8,<3.15`，沿用已有外部解释器绑定。已有项目无需重新注册。

性能测试方法与结果见[开发说明](../development.md#性能与边界)。完整命令和退出码见[接口约定](../cli-contract.md)。

## English

- Adds Windows / WSL toolbox commands: `ports list/show` inspects live sockets and owners, `which` traces PATH candidates, and `net info/check` inspects network settings and diagnoses direct connections by stage. Bidirectional calls and JSON are supported.
- Collects port data on demand using native Windows APIs through the standard library. WSL skips process scans when no ports match. Git monitoring uses one invocation per poll instead of three; discovery walks metadata once.
- Scanning and monitoring skip directory junctions, symlinks and nonregular metadata files. Invalid declarations produce validation errors, and one damaged registration no longer hides other projects.
- Disabling report refresh now skips npm update queries. SSH Include expansion is bounded; Compose health queries time out after 5 seconds.
- Bare toolbox commands display help. SSH supports source inspection, editing and native connections. Windows hosts supports profiles, editing, conflict checks, automatic backups and restoration.
- `list` defaults to the current environment; `--all` combines both. Projects, preferences, reports, SSH and controller maintenance share `-e win|wsl`. `self status` describes the selected deployment using schema_version=1.
- Fixes Windows PowerShell discovery under WSL root/sudo, held Windows preference files, special-character forwarding and report paths. Improves update recovery, lint checks and bilingual documentation.

Queries remain read-only; system hosts writes request elevation when needed and create backups. Controller Python still requires `>=3.14.8,<3.15` and preserves external interpreter bindings. Existing projects do not need registration again.

See [development notes](../development.en.md#performance-and-boundaries) for benchmark methods and results, and the [CLI contract](../cli-contract.en.md) for commands and exit codes.
