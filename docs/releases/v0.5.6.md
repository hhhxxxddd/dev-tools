# dev-tools v0.5.6

## 中文

- hosts 与 SSH 增加 `list --edit` 交互列表，支持编辑、新增、删除和显式保存；hosts 可切换启用状态。保留原有文本编辑入口，复用校验、并发检测和备份流程，保存失败或中断时保留草稿。
- 日志位置参数统一为项目名和服务名；支持项目日志汇总、任务日志与双向 `-e win|wsl --follow`。分块读取保留 UTF-8 与换行状态，跟进轮转、截断和后创建的日志。
- 跨端交互编辑使用目标侧终端能力，保留终端恢复与中断处理。普通文本与 JSON 查询使用相同的 30 秒传输超时，持续日志和动作不使用该查询超时，NO_COLOR 与交互终端能力分开处理。
- 修复 Windows IPv4/IPv6 TCP 监听行状态差异。Windows→WSL HTTP 访问检查改用 GET，兼容仅支持 GET 的服务；通用 net check 保留 HEAD。SSH Include 的并发检查覆盖链接落点变化，并补齐敏感命令隐藏与 hosts 保存后的错误提示。
- 重写双语 README，按用途、操作演示、安装、上手、项目类型、工具箱和配置组织，加入 42 秒实际样例演示及封面；生成工程与缓存不进入安装包，修正文档中的旧日志命令。

已有项目无需重新注册。两端控制器分别更新后使用新的日志参数和交互编辑约定；hosts 仍仅管理 Windows。

详见[运行说明](../usage.md)、[CLI 约定](../cli-contract.md)和[中文 README](../../README.md)。

## English

- Adds interactive `list --edit` for hosts and SSH, supporting edits, additions, deletions and explicit saves. Hosts entries can be enabled or disabled. Existing text editors remain available; validation, concurrency checks and backups are reused, and failed or interrupted saves retain drafts.
- Log positional arguments consistently identify the project and service. Supports combined project logs, task logs and bidirectional `-e win|wsl --follow`. Chunked reads preserve UTF-8 and newline state while following rotation, truncation and newly created files.
- Cross-environment list editing uses the target terminal, with terminal restoration and interruption handling. Plain-text and JSON queries share a 30-second transport timeout; following logs and actions do not use that query timeout. NO_COLOR is handled separately from terminal interactivity.
- Fixes Windows IPv4/IPv6 TCP listener state differences. Windows-to-WSL HTTP access checks use GET for services that only implement GET; general net check retains HEAD. SSH Include concurrency checks cover changing link targets; sensitive commands are redacted and hosts save errors are reported.
- Rewrites both READMEs around purpose, an operation walkthrough, installation, getting started, project types, tools and configuration. Includes a 42-second verified sample video and poster, excludes its generation project and caches from installation packages, and corrects outdated log commands.

Existing projects need no registration again. Update both controllers before using the new log arguments and interactive editing contract. Hosts still manages Windows only.

See [operation](../usage.en.md), the [CLI contract](../cli-contract.en.md) and the [English README](../../README.en.md).
