# dev-tools v0.5.0

## 中文

- `list --all` 统一列出 Windows 和 WSL 项目，以调用端语言和相同表格展示；一侧不可用时保留另一侧结果，并明确报告不完整。
- 新增只读 `check` 查看完整准备计划；`scan` 和 `check` 不写配置、不安装运行时，也不触发 WSL 部署。移除公开 `--dry-run`，`prepare --json` 仍实际执行准备。
- 两平台可绑定已有原生 Python 3.14.8，Windows 使用 `.host-python.win`，WSL 使用 `.host-python`。重复部署沿用本平台绑定；解释器失效时明确失败，不升级或删除外部 Python。
- 新增 `-v` 和顶层 `upgrade`，`self upgrade` 是同一入口。Git 更新验证官方来源，只允许干净分支快进；发行包校验后更新，Scoop 安装通过 Scoop 更新。
- 注册存储版本与 CLI 输出版本分别管理，补充本机缓存路径校验；统一子进程超时、失败诊断与恢复建议。服务日志自动轮转，并从文件尾读取。
- 正常停止的服务不再误报工作进程意外退出，真实失败仍保留原始诊断。
- 固定 CLI JSON、错误码与退出码约定：检查阻塞和查询不完整返回 1，参数错误返回 2，中断返回 130。机器字段和状态标识不随语言切换，第三方日志与 JSON 分流。
- 重写简洁的中英文 README、依赖要求表和安装说明，Scoop 清单统一由 hxd-box 维护。
- 新增 Windows/Ubuntu 日常 CI、文档/TOML 校验和完整解压包原生入口验证。正式构建要求版本、tag、干净源码与提交一致，两平台产物逐字节相同；提供包含源码来源和逐文件校验的完整 ZIP、SHA256SUMS 与 Scoop 清单，已发布附件不覆盖。

升级前停止使用目标控制程序的项目，升级后按需重新启动。部署保留项目注册、偏好、状态、缓存、项目运行时与外部 Python。项目 JSON 与本机注册仍为 schema_version=3，项目声明仍为 schema=1，不因本次程序版本变化而迁移。

## English

- `list --all` combines Windows and WSL projects using the caller's language and the same table layout. If one platform is unavailable, results from the other remain available and the incomplete query is reported.
- New read-only `check` shows the complete preparation plan. `scan` and `check` do not write configuration, install runtimes or deploy WSL. Public `--dry-run` options are removed; `prepare --json` still executes preparation.
- Both platforms can bind existing native Python 3.14.8: `.host-python.win` on Windows and `.host-python` in WSL. Repeated deployment retains the native binding, fails clearly on invalid interpreters and never upgrades or removes external Python.
- New `-v` and top-level `upgrade`; `self upgrade` is equivalent. Git updates verify the official source and only fast-forward clean branches; packages are verified before deployment, and Scoop installations update through Scoop.
- Registration storage versions are separated from CLI output versions, and native cache paths are validated. Subprocess timeouts, failure diagnostics and recovery suggestions are consistent. Service logs rotate automatically and are read from the tail.
- Normally stopped services no longer report an unexpected worker exit; actual failures retain their original diagnostics.
- CLI JSON, error codes and exit codes now have documented contracts: blocked checks and incomplete queries return 1, invalid arguments return 2, and interruption returns 130. Machine fields and status identifiers do not change with language; third-party logs remain separate from JSON.
- Concise bilingual READMEs, dependency tables and installation guides now use hxd-box for Scoop manifests.
- Daily Windows/Ubuntu CI checks documentation, TOML and native entrypoints from complete extracted packages. Official builds require matching versions, tags, clean sources and commits, with byte-identical platform assets. Complete ZIP packages include source provenance and per-file checksums, accompanied by SHA256SUMS and Scoop manifests; published assets are never overwritten.

Stop projects using the target controller before upgrading, then restart them as needed. Deployment preserves registrations, preferences, state, caches, project runtimes and external Python. Project JSON and native registrations remain at schema_version=3, and project declarations remain at schema=1; this tool version does not migrate those formats.
